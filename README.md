# Proper-Time-Physics-Institute.github.io

Public website for the [Proper-Time-Physics-Institute](https://github.com/Proper-Time-Physics-Institute)
org → served at <https://proper-time-physics-institute.github.io/>.

Built with **Astro**. Content is **assembled at build time** from the org's content repos
(`quantum`, `electromagnetic`, `relativistic-dynamics`, `commons`, `animations`, `podcasts`)
by [`scripts/sync-content.mjs`](scripts/sync-content.mjs), so the site tracks each repo's `main`.
Source repos stay private; this site is public.

## Sections
Papers (arXiv/DOI links) · Derivation videos (Manim) · Problem library (Jackson / Griffiths /
Bethe–Salpeter / GPS) · Research roadmap · Podcasts (NotebookLM).

## Local development
The content repos are expected as sibling clones (`../quantum`, `../commons`, …).
```bash
npm install
npm run sync           # assemble content from ../<repo> (pass a path to override)
npm run dev            # http://localhost:4321
npm run build && npm run preview
```

## What is committed vs generated
- **Committed:** Astro source, `src/data/papers.yaml` (curated — seeded from arXiv, review before publish).
- **Generated by `sync` (git-ignored):** `src/content/problems/`, `src/content/roadmap/`,
  `src/data/{videos,podcasts}.yaml`, `public/videos/`, copied branding assets.

## Deploy
GitHub Actions ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)) checks out the
content repos (using the `CONTENT_PAT` secret — a fine-grained PAT with read access to the
content repos), runs `sync`, builds, and deploys to Pages on every push to `main`.

## Podcasts audio
Episodes are listed in `podcasts/episodes.yaml` (in the `podcasts` repo); audio files are uploaded
as **GitHub Release assets** on that repo and referenced by `audio_url`.
